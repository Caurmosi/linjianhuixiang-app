# 《林间回响》云端后端部署手册（含置信度）

> 目的：把 Sealos 云上后端从旧镜像升级到含「宜居度置信度」计算的新镜像。
> 状态时间：2026-08-16

## 1. 背景与现状

- 置信度功能已在本地完成并推送 main（commit `189de44`）：analyze 返回 `confidence`（0–1）+ `confidenceLabel`（高/中/低）。
- **实测云上后端（`https://uegbddmczvrm.cloud.sealos.io`）仍是旧镜像**：
  ```bash
  curl -F "file=@backend/assets/sample_bird.wav" https://uegbddmczvrm.cloud.sealos.io/api/analyze
  # 返回的 JSON 中 confidence / confidenceLabel 为 undefined（缺失）
  ```
- 镜像自动构建链路：push main 且 `backend/**` 或 workflow 文件有改动 → GitHub Actions 构建 `ghcr.io/linjianhuixiang-app/linjianhuixiang-backend:latest`（内置真实 BirdNET 模型，约 170MB）→ 自动设为 public。

## 2. 本次已修复的问题（commit `ed5894c`）

- **Bug**：CI 中"镜像设 public"的 PATCH 请求包名未做 URL 编码（`linjianhuixiang-app/linjianhuixiang-backend` 中的 `/` 必须编码为 `%2F`），导致请求 404、镜像保持 **private**，Sealos/Zeabur 匿名拉取必失败（表现为 ghcr.io 匿名 token 返回 `403 DENIED`）。
- **修复**：`%2F` 编码 + 失败时输出 HTTP 状态码与 warning，便于排查。
- 已推送，会自动触发一次完整重建（含置信度 + public 设置）。

## 3. 部署步骤（浏览器操作，约 10 分钟）

### 3.1 确认镜像构建成功
1. 打开 GitHub → 仓库 `Caurmosi/linjianhuixiang-app` → **Actions** 页签。
2. 找到最新一次 **"Build Backend Docker Image"** 运行（应由 `ed5894c` 触发），等待绿色 ✅ 完成。
   - 若失败：展开失败步骤查看日志（常见：Zenodo 模型下载超时 → 点右上角 **Re-run all jobs** 重试）。

### 3.2 确认镜像可见性为 Public
1. 打开仓库 **Packages** 页签（或 https://github.com/Caurmosi?tab=packages ）。
2. 找到 `linjianhuixiang-backend`，确认右侧显示 **Public**。
3. 若仍显示 Private：点击进入包详情 → 右侧 **Package settings** → **Change visibility** → 设为 **Public**（CI 修复后一般会自动成功，手动兜底）。

### 3.3 Sealos 控制台重新部署
1. 登录 https://cloud.sealos.io → 进入部署了后端的 **应用管理 / App Launchpad**。
2. 找到后端应用（镜像 `ghcr.io/linjianhuixiang-app/linjianhuixiang-backend:latest`）。
3. **重新部署**：编辑应用 → 镜像地址不变（latest）→ 保存并重建；或删除应用后用同一镜像配置重新创建。
   - 若平台缓存旧 digest：可将镜像地址改为 `:sha-<commit前7位>`（如 `sha-ed5894c`）强制拉新。
4. **内存建议 ≥1.5GB**：BirdNET 模型推理内存峰值 500MB–1GB，免费实例默认内存易 OOM（曾出现 503 no healthy upstream）。在应用配置中把内存调至 1–2GB。

### 3.4 验证（任选其一）
```bash
# 方式一：样例音频打真实接口
curl -F "file=@backend/assets/sample_bird.wav" \
  https://uegbddmczvrm.cloud.sealos.io/api/analyze
# 期望：JSON 中出现 "confidence": 0.xx, "confidenceLabel": "高|中|低"

# 方式二：索引接口不受影响（旧版也返回，仅作连通性确认）
curl https://uegbddmczvrm.cloud.sealos.io/api/indices
```
前端检测到 `confidence` 字段后，宜居度大卡会自动显示「置信度 高（72%）」徽标（缺失则不渲染，老版本 APK 也安全）。

## 4. 回滚

若新镜像异常：
- 在 Sealos 应用配置中把镜像改回上一次可用 tag（如有 `sha-` 历史 tag，见 ghcr.io 包详情页 Versions 列表），或临时指向旧镜像 digest。
- 前端侧无需回滚：`confidence` 字段缺失时徽标自动隐藏，契约字段由 `dataContract.test.js` 守护。

## 5. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| Actions 失败于下载模型 | Zenodo 网络波动 | Re-run all jobs 重试 |
| ghcr 拉取 403 | 镜像 private | 按 3.2 设 Public |
| 云端 analyze 超时/503 | 实例 OOM | 调内存至 1–2GB 后重启 |
| analyze 无 confidence | 仍是旧镜像 | 重新拉 latest 并重建应用 |
